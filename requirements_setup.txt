## Setup Instructions

### For Streamlit Frontend:

1. **Install Dependencies:**
```bash
pip install -r requirements.txt
pip install -r requirements_streamlit.txt
```

2. **Create Project Structure:**
```
data_analyzer_bot/
│
├── streamlit_app.py          # Main Streamlit app
├── data_analyzer_bot.py      # Your bot logic (from previous artifact)
├── requirements.txt          # Common dependencies
├── requirements_streamlit.txt # Streamlit-specific dependencies
└── .streamlit/
    └── config.toml          # Streamlit configuration
```

3. **Streamlit Configuration (.streamlit/config.toml):**
```toml
[theme]
primaryColor = "#3498db"
backgroundColor = "#ffffff"
secondaryBackgroundColor = "#f8f9fa"
textColor = "#2c3e50"

[server]
maxUploadSize = 200
enableCORS = true
enableXsrfProtection = true
```

4. **Environment Variables (.env):**
```env
AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
AZURE_OPENAI_API_KEY=your-api-key-here
AZURE_OPENAI_VERSION=2024-02-15-preview
```

5. **Run Streamlit App:**
```bash
streamlit run streamlit_app.py
```

### For Flask Frontend:

1. **Install Dependencies:**
```bash
pip install -r requirements.txt
pip install -r requirements_flask.txt
```

2. **Create Project Structure:**
```
data_analyzer_bot_flask/
│
├── app.py                   # Main Flask app
├── data_analyzer_bot.py     # Your bot logic
├── requirements.txt         # Common dependencies
├── requirements_flask.txt   # Flask-specific dependencies
├── templates/               # HTML templates (auto-created)
│   ├── index.html
│   └── results.html
├── static/                  # Static files (CSS, JS)
├── uploads/                 # File uploads (auto-created)
└── .env                     # Environment variables
```

3. **Environment Variables (.env):**
```env
FLASK_APP=app.py
FLASK_ENV=development
SECRET_KEY=your-secret-key-change-in-production
AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
AZURE_OPENAI_API_KEY=your-api-key-here
AZURE_OPENAI_VERSION=2024-02-15-preview
MAX_CONTENT_LENGTH=104857600
```

4. **Run Flask App:**
```bash
# Development
python app.py

# Or with Flask CLI
flask run

# Production with Gunicorn
gunicorn -w 4 -b 0.0.0.0:8000 app:app
```

## Feature Comparison

### Streamlit Frontend Features:
✅ **Pros:**
- Rapid development and deployment
- Built-in data visualization components
- Interactive widgets out of the box
- Automatic UI updates with session state
- Easy file upload and download
- Built-in caching mechanisms
- Great for data science prototypes
- No need to write HTML/CSS/JS

❌ **Cons:**
- Less customization control
- Limited styling options
- Session management can be tricky
- Not ideal for production web apps
- Performance issues with large datasets
- Limited real-time capabilities

### Flask Frontend Features:
✅ **Pros:**
- Full control over UI/UX design
- Highly customizable with HTML/CSS/JS
- Better for production applications
- Excellent session management
- RESTful API design
- Scalable architecture
- Better security controls
- Real-time capabilities with WebSockets

❌ **Cons:**
- More development time required
- Need to write frontend code
- More complex deployment
- Manual state management
- Requires more web development knowledge

### 2. Advanced Data Validation
```python
def validate_uploaded_data(df):
    issues = []
    recommendations = []
    
    # Check data quality
    if df.empty:
        issues.append("Dataset is empty")
        return issues, recommendations
    
    # Check for sufficient data
    if len(df) < 10:
        issues.append("Dataset has fewer than 10 rows - results may not be reliable")
    
    # Check for missing values
    missing_pct = (df.isnull().sum().sum() / (df.shape[0] * df.shape[1])) * 100
    if missing_pct > 50:
        issues.append(f"Dataset has {missing_pct:.1f}% missing values")
        recommendations.append("Consider data cleaning or imputation")
    
    # Check for data types
    if len(df.select_dtypes(include=[np.number]).columns) == 0:
        recommendations.append("No numeric columns found - consider encoding categorical variables")
    
    return issues, recommendations
```

## Security Considerations

### Input Validation
```python
ALLOWED_EXTENSIONS = {'csv', 'xlsx', 'xls', 'json'}
MAX_FILE_SIZE = 100 * 1024 * 1024  # 100MB

def allowed_file(filename):
    return '.' in filename and \
           filename.rsplit('.', 1)[1].lower() in ALLOWED_EXTENSIONS

def secure_file_upload(file):
    if not allowed_file(file.filename):
        raise ValueError("File type not allowed")
    
    if len(file.read()) > MAX_FILE_SIZE:
        raise ValueError("File too large")
    
    file.seek(0)  # Reset file pointer
    return secure_filename(file.filename)
```

## Monitoring and Logging

### Logging Configuration
```python
import logging
from logging.handlers import RotatingFileHandler

def setup_logging(app):
    if not app.debug:
        if not os.path.exists('logs'):
            os.mkdir('logs')
        
        file_handler = RotatingFileHandler('logs/data_analyzer.log', 
                                         maxBytes=10240, backupCount=10)
        file_handler.setFormatter(logging.Formatter(
            '%(asctime)s %(levelname)s: %(message)s [in %(pathname)s:%(lineno)d]'
        ))
        file_handler.setLevel(logging.INFO)
        app.logger.addHandler(file_handler)
        
        app.logger.setLevel(logging.INFO)
        app.logger.info('Data Analyzer Bot startup')
```

## Troubleshooting

### Common Issues:

1. **Azure OpenAI Connection Issues:**
   - Verify endpoint URL format
   - Check API key validity
   - Ensure model deployment name is correct

2. **File Upload Problems:**
   - Check file size limits
   - Verify file format support
   - Ensure proper encoding (UTF-8)

3. **Memory Issues with Large Datasets:**
   - Implement data chunking
   - Use streaming for file processing
   - Add progress indicators

4. **Session Management:**
   - Clear old sessions regularly
   - Implement session timeouts
   - Use database for persistent storage

### Performance Optimization:

1. **Data Processing:**
   - Use pandas efficiently
   - Implement data sampling for large datasets
   - Cache frequent operations

2. **Frontend Optimization:**
   - Minimize JavaScript bundle size
   - Use CDN for static assets
   - Implement lazy loading

3. **Backend Optimization:**
   - Use async processing
   - Implement connection pooling
   - Add response compression
